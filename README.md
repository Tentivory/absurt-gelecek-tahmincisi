# Absürt Gelecek Tahmincisi

Bu repository, insanlığın en büyük sorularından birine cevap arar: **Yarın ne olacak?**

Cevap: Muhtemelen bir şeyler. Belki de hiçbir şey. Ama biz bunu **son derece ciddi** bir şekilde tahmin ediyoruz.

## Nasıl Çalışır?

1. Python 3 ile çalıştırın.
2. Adınızı verin.
3. Evrenin size özel absürt ama teknik olarak mümkün olan gelecek tahminini alın.

```bash
python tahminci.py
```

veya

```bash
python tahminci.py Ahmet
```

## Neden Bu Kadar Ciddi?

Çünkü absürtlük de bir bilimdir. Belki de değildir. Ama biz öyle davranıyoruz.

Bu proje, özellikle "ya acaba?" diye düşünenler için tasarlanmıştır. Tahminler rastgeledir ama kalbiyle değil, `random` modülüyle seçilir. Bu da onu neredeyse bilimsel yapar.

## Uyarı

Bu tahminler gerçekleşebilir. Gerçekleşmeyebilir. Gerçekleşirse "ben demiştim" diyebilirsiniz. Gerçekleşmezse "zaten şakaydı" diyebilirsiniz. Her iki durumda da kazanırsınız.
